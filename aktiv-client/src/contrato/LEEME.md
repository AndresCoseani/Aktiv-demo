# Contrato de datos (copia)

Esta carpeta es una **copia** del contrato que vive en el repo **aktiv-api** (`contrato/src`).
**No la edites a mano**: cualquier cambio se hace en aktiv-api y después se trae acá con:

```
npm run contrato:sync     # copia desde ../aktiv-api
npm run contrato:check    # verifica que coincidan
```
